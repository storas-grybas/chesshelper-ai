# ChessHelper.ai — AI chess analysis assistant

Best-move suggestions with a plain-English explanation, right on the board. Works on Chess.com and Lichess.

## What it does

ChessHelper.ai reads the position you're playing, evaluates it with a chess engine, and shows you the strongest move **and the idea behind it** — the threat, the plan, the trade-offs — instead of a bare eval bar. Built to help you understand your moves and openings, not just copy them.

- Real-time best-move suggestions with move arrows and position evaluation
- Plain-English explanations of *why* a move is best
- Openings trainer and ELO-calibrated suggestions (800–3200), with a human-like mode
- Chrome extension for Chess.com and Lichess, plus web tools for analysing any position (paste a FEN, get the line)
